# Code of Conduct

## Our Standard

This project is for practical, respectful collaboration around Japanese web UI quality gates. Contributors and maintainers are expected to:

- Use welcoming and inclusive language.
- Respect different experience levels, languages, and accessibility needs.
- Give feedback about the work, not the person.
- Avoid harassment, insults, discriminatory language, sexualized attention, and repeated unwanted contact.
- Keep examples free of secrets, credentials, private repository URLs, customer data, and real operational logs.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that do not meet this standard. They may also block accounts from future participation when behavior creates safety, privacy, or maintenance risk.

## Reporting

For ordinary conduct concerns, open a GitHub issue with only non-sensitive context. For security-sensitive conduct concerns that include private data, credentials, or vulnerability details, follow [`SECURITY.md`](SECURITY.md) and avoid posting sensitive material publicly.
